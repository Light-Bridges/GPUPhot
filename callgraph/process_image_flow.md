## 5. Main routes and logical branching

Critical path (background/conv):
- `calibrate_image` -> `get_local_background_fft` -> `get_mean_std` ->
  `gen_apm_filter` -> `convolve_fft`

Comments:
- `convolve_fft` is a sensitive point due to padding and temporary memory usage.
- If OOM is detected you should try:
  1) free memory (from variables, call mempool free if it exists)
  2) reduce tile-size or process by tiles
  3) CPU fallback for that specific operation

Optimized photometry path:
- `process_image` -> `perform_opt_photometry` ->
  `create_aperture_corrections_map_gpu` -> `batch_aperture_photometry`

Branching (conditions/alternatives):
- cuML available: use GPU implementations (crossmatch, clustering,
  PCA) -> solid edges towards `*_gpu_impl`.
- cuML not available: fallback to CPU (`sklearn`/`numpy`) -> edges inDOT marked as `dashed`.
- OOM: `batch_aperture_photometry` and `calibrate_image` already implement
  OOM handling (try to release and try again or crash to CPU).
